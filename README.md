# Todo List

Aplicação de gerenciamento de tarefas desenvolvida para prática de React e manipulação de estado.

## Funcionalidades

- Adicionar tarefas
- Remover tarefas
- Editar tarefas
- Marcar tarefas como concluídas
- Filtrar tarefas por estado de conclusão
- Persistência com localStorage

## Tecnologias

- React
- Vite
- Styled Components

## Como executar

```bash
npm install
npm run dev
```
